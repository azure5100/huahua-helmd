# huahua-helmd

**DSH host plugin: a portable security knowledge base + H-CoT settings + health check**

[![License: MIT](https://img.shields.io/badge/License-MIT--huahua--parts-3DDC84.svg)](LICENSE)

</div>

---

`huahua-helmd` bundles 362 domain-organized security reference documents into a DSH host plugin, so the model can consult real references instead of guessing. It also ships two utilities: an **H-CoT settings surface** and a **host health check**.

## What you get

| Part | Detail |
|---|---|
| `references/` | 362 markdown files across 9 domains: web, protocol, android, native, malware, ai-security, evidence, toolbox |
| `helmd-health` | Plugin main entry; verifies patches applied, deps present |
| `helmd-hcot-settings` | Own settings namespace + UI data plane, registered as a separate row |
| `presets/helmd` | Agent preset generated by `scripts/gen-preset.mjs` |

## Install

```bash
dsh plugin --profile desktop add "github:azure5100/huahua-helmd"
# restart the host — bundle plugins need a full restart
```

## Requirements

```
DSH  >= 0.2.1-rc.2
Node >= 20
peer: @deepseek-ai/cordis ^4.0.2 · dsh-settings · dsh-tools · schemastery
```

## Antivirus note

Files under `references/` contain executable payload samples (webshell one-liners, reverse-shell commands). Signature engines label them by payload family (`Backdoor:PHP/Chopper`, etc.). These are **plain .md text files**; no process executes them. Add a path exclusion if your AV complains.
